[ 01 ] // proceso

Cómo funciona

Tres pasos, y el servidor tiene siempre la última palabra.

✎ FASE_01

Envías lo que quieres

Tipo de web, número de páginas, formulario y segundo idioma. Solo esos cuatro campos.

✓ FASE_02

El servidor valida

Si falta un campo o un valor no es válido, responde 400 explicando exactamente qué está mal.

∑ FASE_03

Calcula con sus tarifas

Base + páginas adicionales + extras. Si alguien envía su propio "total", se ignora.

[ 02 ] // tarifas

Tarifas

Cargadas en directo desde GET /api/tarifas. Sin impuestos ni descuentos.

    La API

    Tres rutas. JSON de entrada, JSON de salida.

    GET /api/estado

    Comprueba que el servicio funciona.

    comprobando…
    GET /api/tarifas

    Devuelve las tarifas que usa el servidor.

    POST /api/presupuesto

    Recibe tipo, paginas, formulario y segundoIdioma y devuelve el desglose.

    terminal
    $ curl -X POST http://localhost:4000/api/presupuesto \
    -H "Content-Type: application/json" \
    -d '{"tipo":"landing","paginas":2,"formulario":true,"segundoIdioma":true}'

{ "base":300, "paginasAdicionales":50, "formulario":80, "segundoIdioma":150, "total":580, "moneda":"EUR" }
